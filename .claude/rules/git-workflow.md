# Git Workflow

**Never work directly on main.** Branch → Commit → PR → Merge.

## Branch Naming

- `fix/description` — bug fixes, compatibility fixes
- `feat/description` — new skills, plugins, features
- `refactor/description` — restructuring without behavior change

## Commits

- Small, focused commits
- Conventional commit messages: `fix(plugin): description`, `feat(DIP): description`
- Co-author line for AI-assisted commits

## PRs

- Wait for review bot before merging
- Address blocking (red) issues before merge
- Yellow/blue observations are advisory
